# BDA400 Assignment 6 - Technical Analysis Using R

**Student:** Omar Halfaoui

## Project Description

This project implements an interactive stock technical analysis dashboard using R Shiny. The application retrieves historical stock data from Yahoo Finance and provides interactive visualization of stock prices.

The dashboard includes Moving Averages, RSI, and MACD technical indicators, along with Buy, Sell, and Hold trading signals based on Moving Average crossover rules.

## Technologies Used

- R
- Shiny
- ggplot2
- quantmod
- Yahoo Finance
